怎么拿这个 Token？（30 秒，免费）

1. 电脑或手机浏览器打开 github.com 并登录（没有就注册一个，免费）

2. 右上角头像 → Settings → 左下角 Developer settings

3. Personal access tokens → Tokens (classic) → Generate new token (classic)

4. Note 随便填（比如 couple），Expiration 选 No expiration

5. 只勾选 gist 这一项，滚到底点 Generate token

6. 复制那串 ghp_ 开头的字符，粘到上面输入框

这串相当于你私人保险箱的钥匙，只会存在你们两台手机里，不会上传到任何第三方。

创建成功后会生成一串「邀请码」，发给她的手机粘贴一次，就配对了。

粘贴后会自动连上他创建的空间，之后你写的内容他那边几秒就能看到。

用「我们」页里复制的恢复码。它会连回原来的空间，而且身份还是你自己，不会变成她。恢复码和邀请码不是一回事：邀请码是给人用的，恢复码只留给自己。
